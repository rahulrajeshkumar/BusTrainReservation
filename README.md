# Bus and Train Reservation System

## Project Overview

A reservation management application developed using Python, Streamlit, and Oracle Database. It provides an interface for managing trips, seat reservations, cancellations, payments, and reports.

## Technologies Used

* Python
* Streamlit
* Oracle Database
* python-oracledb

## Features

* Dashboard
* Search Trips
* Book a Seat
* Manage Reservations
* Payments
* Reservation Reports
* Payment Reports
* Trip Summary

## Running the Application Locally

1. Install Python.

2. Install the required dependencies:

   `pip install -r requirements.txt`

3. Configure the Oracle database connection.

4. Start the application:

   `python -m streamlit run app.py`

## Database Requirements

The application requires an Oracle database with the necessary reservation-system tables, procedures, functions, and triggers configured.

## Deployment

The application can be deployed through Streamlit Community Cloud after configuring a database that the hosted application can access.
